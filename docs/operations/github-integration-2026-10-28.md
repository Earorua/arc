## 合并审查发现并修复的兼容性问题

1. 作品页先加载编辑器、后恢复云端目标时，未按真实目标重新读取草稿。编辑器现在按完整账户、目标和编辑上下文重新挂载，并防止草稿串到另一目标。
2. 无指定来源的登录把成功返回的基础计划误判为没有计划。现在只有明确的缺失目标响应才进入设置；基础计划与自适应计划均返回今日学习。
3. 旧基础计划的时间编辑入口误入只支持自适应计划的页面。现在通过原有、受账户约束的保存接口仅更新每周分钟数，保留目标、自评与完成记录，并处理断线、登录过期和离开时的取消。

上述问题均先通过回归测试复现，再修复。相关八个文件的 135 项测试通过；独立复核最终为 Critical 0 / Important 0 / Minor 0。
