- **20 张旧表全部非空，共 50 行**：两个 owner、账户/会话、关联意图、验证/档案、活动与历史目标、旧任务/完成事件、Proof/分享、配额、幂等和设备迁移回执、运营/速率/旗标记录。固定数据中的 JSON 空白/键顺序、NULL、Unicode 和引号按原文本保存。

- **7 项恢复前拒绝**：SQL 哈希漂移、改动行、缺失行、缺失对象、对象字节损坏、非空数据库、非空 bucket。缺失行/对象与损坏对象用例重新计算外层 checksum，确实进入各自内容校验；目标的完整内容指纹保持不变。
- **6 项数据库拒绝**：重复活动目标、重复幂等身份、缺失 owner、跨 owner 规划、跨 owner Proof、包含非法第二步的原子 batch。合法新规划/Proof 行先成功写入；拒绝后检查实际行指纹，并再次核对全部旧数据和数据库健康。

## 恢复证据的含义

本轮针对静止状态的合成旧库建立逻辑快照，并恢复到另一个全新隔离 D1/R2；恢复源不被删除或原地重用。它补充实际本地 workerd 上的数据与对象恢复证据，不是生产数据备份。

完整升级、恢复基线和恢复后的再次升级均通过 `PRAGMA foreign_key_check` 与 **`PRAGMA quick_check`**。workerd 对完整 `PRAGMA integrity_check` 返回 `SQLITE_AUTH`；本轮没有宣称它运行成功，使用受支持的快速检查并辅以全量旧行/索引比较与约束用例。故意中断的迁移前缀可能尚未创建复合外键需要的父索引，因此不把这个不完整库宣称为健康状态，也不盲目重跑非幂等 CREATE 文件。恢复路径从原始快照建立全新目标。

未验证项目仍包括生产已应用迁移 ledger、Cloudflare 原生备份/Time Travel、生产迁移执行器的中断/重试语义、保留旧应用完整读写兼容、线上 artifact、真实 OAuth 和真实 Research。产品 `migration_runs` 保存的是设备数据迁移回执，不是 D1 schema ledger。

本轮没有新增真实 Provider 请求、读取真实 Key，或操作生产变量/旗标/D1/R2、master 合并、PR、Sites 候选和部署。对外报告只能称为本轮具体本地演练通过，不能等同于目标 2 真实验收或目标 3 发布完成。
