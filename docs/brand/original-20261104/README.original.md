# Arc. 品牌标志

![Arc. 的完整字标、深底独立图形和浏览器图标](./arc-identity.png)

A 的左脚伸出一段向上的弧线，朱橙圆点标记这条路上的「今天」。在完整字标里，它是 Arc. 的首字母；独立使用时，它仍是同一条路径。

| 文件 | 用法 |
| --- | --- |
| [完整字标 · SVG](../../public/brand/arc-logo.svg) | 页头、文档封面和对外署名。字形均已转为路径，无需安装字体。 |
| [独立 A · SVG](../../public/brand/arc-mark.svg) | 正方形头像、应用图标或已出现品牌名的位置。背景透明。 |
| [完整字标 · 透明 PNG](./arc-logo.png) | 不支持 SVG 的演示文稿、邮件或文档。1296 × 528 像素。 |
| [浏览器图标 · SVG](../../public/favicon.svg) | 为 16–32 像素重新调整了笔画和圆点，保留纸白底。 |
| [分享封面 · PNG](../../public/og.png) | 项目链接预览。1672 × 941 像素。 |

浅色背景用炭黑 `#171715`，深色背景用纸白 `#F3EFE6`；两者的节点均为朱橙 `#F0643E`。独立 SVG 的根元素 `color` 属性控制字色。页面内的字标继承文字颜色，不需要额外下载图片或字体。

网页和两个标准矢量文件共用一份[字形轮廓](../../app/components/brand/arc-lettering.json)。修改轮廓后，运行 `node scripts/export-arc-logo.mjs` 即可更新矢量文件。
