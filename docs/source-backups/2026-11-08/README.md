# Historical source preservation

This archive preserves 13 unique files found in older working copies while consolidating the current application. Every other non-brand historical implementation audited was already represented in retained Git history. Brand source is preserved separately under docs/brand/.

The files are superseded plans, older Research runtime/build/test variants, and historical README/checkpoint assemblies. They are reference material, not current application code. Do not overlay application paths or execute archived release commands.

See [the manifest](./manifest.json) for each original relative path, SHA-256, byte count, classification, and reason it was not merged into the runtime. Archive integrity and every extracted file hash were checked. Choose the active source through [SOURCE_INDEX.md](../../../SOURCE_INDEX.md).
