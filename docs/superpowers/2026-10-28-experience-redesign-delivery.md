## 1. 本轮落实的体验

全站沿用首页的暖纸色、墨色文字、克制的紫色操作与衬线标题。工作页收紧标题尺度、限定阅读宽度、统一细线与留白，让任务内容比装饰更突出；资料、说明、生成信息和版本记录按需展开。

| 页面 | 已落实的改变 |
| --- | --- |
| 首页 | 保留原有视觉方向；已有账号浏览首页时不再自动跳走。主内容支持键盘跳过导航。 |
| 登录 | 紧凑、中文、单一登录焦点；保留合法来源、查询参数及失败重试上下文；已过期的缓存身份可以重新认证。 |
| 创建路线 | 使用明确步骤名称；技能先呈现当前组，其他内容折叠；每周总时间与快捷档位优先，按天安排和例外后展开；返回、刷新和同账户草稿恢复。 |
| 编辑时间 | 直接读取当前目标的时间安排；先预览差异，再明确采用或保留原安排；不借编辑时间新建目标。 |
| 学习路线 | 当前目标、继续学习、规划与时间编辑关系明确；单元使用紧凑行与可展开详情，定位可以刷新恢复。历史模式保持只读。 |
| 今日学习 | 按任务、成果、资料、步骤、完成排列；次要说明与周安排折叠；完成后保留明确回执，添加作品带入任务和技能。 |
| 技能与资料 | 左索引支持名称/说明搜索与类别筛选；推荐资料先于来源元信息；技能、筛选、搜索、滚动与返回焦点可恢复。 |
| 作品证据 | 默认是作品列表；新建、查看、修订分开；作品、任务和来源可定位；默认私密，保留修订版本、上传与撤回流程；表单草稿按账户与目标隔离。 |
| 学习规划 | 输入初始为空；当前目标、每周时间和完成进度简明呈现；已生成建议优先显示，输入与生成信息折叠；草稿恢复、来源返回、已保存建议定位与运行中离开提示。 |
| 历史计划 | 分页与目标详情反映在地址中；返回恢复列表位置和焦点；历史路线只读，版本列表折叠。 |

| 管理页、404、异常状态 | 使用紧凑工具页尺度；区分登录与权限不足；不存在页面提供品牌内恢复入口；错误文案与重试动作更清楚。 |

## 2. 导航与状态规则

- 主导航固定为今日学习、学习路线、技能与资料、作品证据；规划、历史、编辑时间和新建路线放在工具菜单。
- 手机使用四项底部导航；输入时为正文与软键盘让出空间，作品操作和伙伴入口避免重叠。
- 登录返回只接受允许的站内页面；来源有选择项时一并保留。首次设置完成后保留路线总览，并提供继续原操作的入口。
- 作品与建议地址必须匹配当前账户可读数据；失效链接有明确状态，不借用其他记录填补。
- 查看、生成建议、预览差异和真正采用分开。作品发布与撤回仍保留现有确认规则。
- 浏览器前进、后退、刷新恢复有意义的页面状态；草稿不放入地址，不跨账户展示。

## 4. 明确保留的能力边界

1. 新建目标沿用现有支持范围：Research 可以创建并归档已有自适应目标；旧版云端/本地已有目标无法安全新建的分支给出说明，不静默覆盖。
2. 修改时间使用现有自适应计划事件与差异确认；没有新增数据库或后台接口。
3. 首次激活成功但生成失败时，原尝试的设置暂时锁定，使用同一标识重试；确认服务结果之前不产生第二份目标。
4. 草稿恢复依赖浏览器存储；规划输入在写入失败时降级为当前运行内存。跨设备恢复不在本轮范围。
5. 生成与当前请求生命周期一致。链接离开和刷新有保护；同页浏览器后退的取消依赖浏览器 Navigation API，缺少该能力时仍保存输入，但不能承诺拦截后退。
6. 未新增后台持续生成、不确定技能校准、历史计划恢复、跨目标搜索或后端契约。
7. 未执行正式部署、真实 OAuth、真实模型付费调用、正式数据写入或真实管理员接口验收。
