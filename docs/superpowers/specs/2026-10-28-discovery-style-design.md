# Arc · Discovery Loop 风格调整

用户要求：以 https://www.discoveryloop.com/ 的动画、色调、字体和字号调整 Arc；沿用已发布完整源码 5858891 / fc9be49。实现分支 codex/ui-discovery-20261028。

## 视觉方向

奶油纸色、轻盈字形和紫色细节，呈现安静、有人文气质的学习工具。首页采用居中大品牌构图；学习工作区保持任务优先。借鉴排版与动效语言，保留 Arc 品牌、原创图形和产品内容。

实际参考（2026-10-28 浏览器与公开 CSS 核对）：背景 #f5efe7、次级底色 #efe7da、正文 #1b1a16、次级正文 #4f4b42、点缀 #8e5db0。Jost 导航和大品牌、Fraunces 展示标题、Newsreader 文章文字。首页品牌约 106px / 400 字重，章节标题最高 64px，正文约 18px。首屏分层淡入 1.1s，滚动内容出现 1s、上移约 26px，图形轻浮动 6.5s，悬停 250–300ms。

Arc 使用相同开源字体家族，本地加载；中文展示文字使用 Noto Serif SC，操作文字继续使用系统中文无衬线，以保持可读性。紫色正文链接使用更深的 #744596 保证浅底对比度，浅紫用于装饰。

## 页面与动效

- 首页：Arc 大字标配原创弧线图形，学习承诺、中文说明、创建路线和完整样例入口；方法、产品样例、末尾行动区组成连续叙事。保留每天 45 分钟 / 18 周的样例标注。
- 全站：统一纸色、细分隔线、圆角轻描边按钮、轻字重标题；工作区一级标题 32–44px，正文 16px / 1.75，操作 14px、注释不小于 12px。
- 学习伙伴：保持独立侧栏 / 手机模态、真实任务上下文、可用状态、发送约束与焦点管理；采用同一字体、紫色与纸色。
- 动画：首页层次淡入、原创弧线轻浮动、章节进入视口的单次淡入；常用工具动作 180–300ms。工作内容不延迟显示。
- 尊重 prefers-reduced-motion；无脚本时正文和入口仍可见；避免动画造成布局位移。装饰不参与辅助技术和点击。
