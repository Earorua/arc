- 服务端校验 planning source，沿用规划服务的账号、目标、版本与 revision 边界。
- 上下文返回当前方向、路线来源、用户本地日期、已完成/总任务数和当前任务的主资料与备选资料。没有当天任务时明确说明，仍允许围绕现有路线提问。
- 模型上下文包含真实进度、当前任务和相同的课程目录；资料只是目录元数据，不声称抓取或读过课程全文。
- 聊天面板展示当前方向、当前任务及可打开的资料链接；建议问题适用于数据、产品和编程等岗位。保持已有桌宠、最小化、隐藏、深入讲解和交给规划师。

- 保留现有模型、费用限制、登录要求、即时流式答疑和请求去重；不自动打开开关或提交真实付费请求。
