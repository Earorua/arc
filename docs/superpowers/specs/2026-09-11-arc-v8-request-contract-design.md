## 方案比较与建议

| 方案 | 收益 | 成本及限制 |
| --- | --- | --- |
| A：在可信系统消息中同步展开完整输出契约（建议） | 消除消息仅泛指 schema 的说明缺口；改动有限，可离线证明消息/参数同源 | 增加输入 token；不能保证模型遵从，也不证明搜索计数问题已解决 |
| B：由应用控制检索，再单独生成结构化候选 | 应用可逐步控制搜索和生成契约 | 需要新的多步骤调用、取消、预算、来源传递和线上执行架构；超出当前单次 POST 方案 |
| C：固定经验证的原生 strict endpoint | 可能提升结构保证 | 尚无本次 endpoint 及其具体能力证据；不能直接猜名称切换或靠反复付费试验 |

先实施 A，并按用户追加选择统一新的10次/50结果策略。若后续真实回执再次超出新上限，仍停止并核对，必要时设计 B 的受控边界；不继续靠盲目重试、降级字段或无依据地再次提高上限。

## A 的精确行为

1. 保持现有 `researchCandidateSchema` 为唯一契约来源。由同一份 `CANDIDATE_JSON_SCHEMA` 生成一个 JSON 文本块，附在可信 Research 系统消息中；response_format 仍引用完全相同的完整 schema、strict true 和现有名称。不手工维护第二份字段表，不删减嵌套教学定义或枚举。
2. 在该块前明确：返回一个契约实例，不能返回 schema 本身；输入 role 是待研究岗位名称，输出 role 必须符合契约的对象类型；所有必需字段、嵌套对象、ID、枚举及引用均按该块生成。保留既有不可信输入/来源隔离、证据、免费替代、完整 learn/calibrate/reinforce 教学要求。不得用空壳或编造内容凑齐必需字段。
3. 在 `provider.ts` 导出冻结 `RESEARCH_SEARCH_POLICY`，包含 policyId `openrouter-web-search-exa-fast-v2`、engine exa、mode fast、maxUses10、maxResults5、maxTotalResults50、maxCharacters2000。提示中的最多搜索数、请求 max_uses/max_tool_calls、结果参数、工厂/本地 fingerprint 及最终验收最大值全部读取这一份配置。最多10次不是要求一定用满10次；达到上限后不继续搜索。提示和参数不能替代远端实际遵从证据，不新增插件、并行开关或停止条件参数。
4. 新契约块只加入 Research 系统提示，作用于共享执行器的标准 Research 和固定 Kimi 本地 Research。Repair 的 `REPAIR_POLICY`、模型、工具禁用状态和拒绝策略保持原状，不带新增契约块。promptVersion 从 `research-prompt-v1` 升为 `research-prompt-v2`；追加搜索策略使 modelConfigVersion 从 `research-model-config-v1` 升为 `research-model-config-v2`。共用标准 Repair 的 user 版本元数据同步更新；input/output/quality 版本不变。`service-factory.ts` 的 POLICY.tool 使用新 policyId，并纳入完整 search 配置；本地 `validation.ts` fingerprint 同样使用它。不沿用旧2次策略的缓存身份，不改线上实际配置。
5. 固定 Kimi profile 仍是 `kimi-low-bounded-v1`，low、600/660/720 秒、12000 max_tokens、一次 GET + 一次 Research POST、Repair 0。profile 标识记录模型/推理/超时策略；提示和搜索变化分别由 promptVersion、modelConfigVersion/搜索 policyId 识别。USD5预留/专用Key限制不变，搜索更多可能增加耗时及费用，不承诺与旧请求相同。
6. 增加的系统消息必须计入既有整个请求 262144 bytes 上限。超过上限时仍在 fetch 之前拒绝，不截断契约。实施后记录标准/本地正常请求的 UTF-8 字节数以及相对旧版本增量；字节数不等于 token 数，不能用上次费用保证新请求费用。
7. 候选解析、字段诊断投影、来源/教学质量、用量双路径、结算、存储、公开旗标不变。通用 usage 现已支持0..10，无需扩展；完整本地验收改为1..10，超过10或非法计数沿用现有拒绝/保守持留行为，不裁剪或推定费用。不读取/记录真实正文，不启用 Response Healing 或 Repair，不把字符串 role 转为对象或生成缺失教学材料。
