## 明确的行为约定

| 已确认事实或关系 | 实践优先级 | 仍保留的内容 |
| --- | --- | --- |
| 本人实际使用、构建、测试SQL，包括无指导、教程辅助或当前练习 | 可以 | 原文、限定、引用和当前能力自评 |
| 明确个人技能陈述，或不含其他主体／时间／否定的常规简历技能片段 | 可以；不表示独立能力 | 原词和课程关系 |
| 同事／团队完成、本人只是安排或记录他人练习 | 不可以 | 已确认事实和课程关系 |
| 计划、希望、条件、示例、转述、整句引用 | 不可以据此推断已有实践 | 原话、限定和主题发现 |
| 明确没有完成／不会执行的动作 | 不可以据此推断已有实践 | 技能主题；不得生成新的uncertain自评 |
| 本人React、同事SQL，或本人SQL、否定React | 逐词处理，只保留有支持的关系 | 两个词的发现和对应结果 |
| 本人写过SQL查询，但没有做过SQL生产配置 | SQL词目标可保留已有实践；具体生产配置任务不能借用查询经历 | 限制与原话保留，不推断生产能力或指导等级 |
| 导师提供SQL，本人只安排演示日程，未说明操作SQL | 不能据此推断SQL实践 | 各自主体与实际动作 |
| 本人明确测试／修改导师提供的SQL，包括有限的参数修改 | 可以安排已有练习；不推断独立编写 | 受指导、有限操作和工具来源限定 |
| 人工把负面SQL事实对应React | 不可以 | 人工选择的课程关系；选择不改变原文主体和极性 |
| 无技能词列表的长个人事实或明确的非字面人工整条对应 | 可以在整条事实支持个人经历时参与 | 人工兜底，不把整条文字作为100字以内的词传入定位器 |
| 整条人工对应跨越不同主体／动作，无法确定所选技能对应哪项个人活动 | 暂不自动给予实践优先级 | 原事实与人工对应；不能借另一项个人活动证明它 |
| 显式空词列表、已删除词、逐词忽略选择 | 不恢复 | 原有移除／忽略语义 |

“未知是否有足够证据”只影响自动实践优先级，不删除事实，也不改成能力不足。已有主JD分类和明确采用的补充学习重点继续按原规则排序。
