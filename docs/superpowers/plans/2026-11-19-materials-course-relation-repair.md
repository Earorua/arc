## 已确认的原因与边界

当前应用基线是 `a5d2fda`，采集工具已保存为 `be9d15f`。课程内容和独立参考不变。独立评分适配的一次软件对照使用原有 30 份构造输入，丢弃其标准课程／计划输出，再调用实际产品组件：原文评分通过，课程关系 146 项中 77 通过、69 失败。结果文件 `work/grounded-verification/kimi-current-20261119-software-diagnostic-result.json`，SHA-256 `13ad19db21a0d8e4abbd1e1b700645c449a9b5d28170541163d8ec806281c430`。这是产品组件差异，不是 Kimi 质量成绩。

代码和课程正文已确认三个原因：现有别名把 CSS、HTML、OpenTelemetry 等过宽地当成课程的字面同名；语境匹配漏掉普通任务说法；九个任务锚点只匹配接近课程原句的表述，并把人物／经历包装也当作尚未覆盖的任务。另有“多课程歧义必然无任务覆盖”的轴混淆，以及会议记录这一行政职责没有归入非学习。

保留原文、词表、人物、否定、时间、能力建议、主 JD 权威和采用机制。课程对应不等于本人做过；做过不等于当前能力；事实确认不等于采用。不能为了评分通过改变这些边界。

## Task A：有限课程语义修复

通过独立实现者、规格审阅、质量审阅完成一个连贯补丁。主要修改 `app/lib/materials/skill-mapper.ts`、`contextual-skill-mapping.ts`、`course-task-coverage.ts`、`course-task-evidence.ts`，必要时作最小契约／呈现调整；不修改提取器、模型提示词、课程数据、历史评分器、独立标注或其摘要。

1. 保留真实本地课程名称作为 literal；修正已证实的过宽默认别名。HTML 表单、测试方法、追踪工具等有实际内容依据时使用 contextual。CSS grid／animation 等无内容依据的范围仍未覆盖。显式旧版本别名 API 继续接受，历史快照不回写。映射策略升至新的 `2026.11.7`，不要让新语义沿用旧版本。
2. 仅补现有语料暴露且当前教学内容支持的有限概念家族：SQL 查询／JOIN／模型，TypeScript 界面逻辑，React 表单／状态／交互测试，语义 HTML 标签，键盘焦点／组件状态，软件测试，软件日志／trace，发布／回滚文档，产品指标。使用词语、同一有效范围的语境及实际课程证据；生产代码不得 import gold、识别文档／字段 ID，或复制每份样例的答案表。
   明确技术词自身可以提供主题对应，例如“没有使用 distributed tracing”仍可显示课程关系，但不进入本人实践。泛词不得从另一人、另一分句或被否定的限定语借来技术领域，例如纸质 logs 后的“not API telemetry”不能使它变成软件日志。保持既有正反边界，不能简单地删除全部否定保护。
3. 将主题对应与具体任务覆盖分开。SQL 聚合、CTE、窗口、空值、参数替换和分析可有主题对应而没有具体课程练习；关系建模、普通 JOIN 的已教子任务按真实引文判断。业务对账、仓库表、重复行解释保留未覆盖范围，不能由 SQL 名称直接推得 full。
4. 以原文中当前词语所指的任务范围评估 coverage。已知人物、时间、指导或经验包装不自动导致 partial，也不转化为能力；未知任务、工具、领域和限定条件仍保留。软换行不能丢掉修饰范围。支持 narrow full、mixed partial、无具体任务 none。不要因同一事实里存在另一个受支持任务，就把无关词语标为受支持。
5. TypeScript schema／narrowing 不作为异步测试或日期格式化的已教子任务；组合任务可同时对应 TypeScript 与 testing，但实际已教部分只能列 testing。React 未限定原型仍 partial，已明确表单／状态／组件测试则按内容判断。UI tokens 只有组件语义／对比度修正子集；Figma 工具无覆盖。
6. 允许课程歧义与任务覆盖独立存在：accessible form labels 的多候选引文并集可覆盖狭窄任务，候选仍未选择，不能声明每个候选都独立覆盖全部。手动只选一个课程时，支持范围只来自被选课程。若现有 UI 不能表明“候选内容合计”，作最小解释调整并增加一项针对性呈现检查。
7. OpenTelemetry／distributed tracing 仅 contextual、有限 partial；trace 与 log 用途区别这一狭窄概念可由实际信号选择内容 full。日志解析器的具体实现不能由“日志”名称获得练习覆盖。通用发布清单可以部分支持迁移审阅和回滚记录，不声明 Kubernetes 操作覆盖。
8. `meeting notes`／`taking meeting notes` 作为明确行政职责 non-learning；混合短语仍保留剩余范围，不能吞掉未教职责。研究目录保持自己的内容边界，不继承旗舰规则。

复用原九个内容锚点；只有现有教学单元提供了缺失的具体证明时才添加必要叶子／任务 ID，例如键盘组件状态和产品指标，不扩写课程。引文必须来自当前本地完整正文；每个支持轨道独立有实际内容，名称或外部 URL 单独不能证明任务覆盖。
