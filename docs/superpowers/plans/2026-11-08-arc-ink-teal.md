# Arc 墨青配色调整

**目标：** 仅调整颜色，让 Arc 的学习、规划、成果积累场景形成独立于 Discovery Loop 的视觉身份。

**边界：** 保持文字、DOM、组件、按钮形状与尺寸、字体字号、间距、布局、SVG 路径、透明度、动效参数和交互逻辑不变。保持成功、错误与禁用状态的语义。

## 设计判断

采用雾白与墨青：较科技蓝温和，较黑白多一个清晰的行动识别色；与现有米黄和紫色组合拉开色相距离。内容与交互结构完整保留。色彩是本次唯一视觉变量。

| 用途 | 颜色 |
| --- | --- |
| 页面底面 | `#F2F6F5` |
| 抬升表面与输入区域 | `#FAFCFB` |
| 次级底面 | `#E5EEEC` |
| 主要文字与深色章节 | `#182B30` |
| 辅助文字 | `#53686C` |
| 分隔线 | `#CAD8D5` |
| 品牌色 | `#237A74` |
| 操作、选中、焦点 | `#176B68` |
| 悬停 | `#115450` |
| 深底强调 | `#95CFC3` |
| 成功 | `#4E7042` |

现有红色错误提示保留其红色语义。阴影仅调整 RGB，保留 alpha、模糊、距离与扩散。Logo、favicon、学习伙伴只更换填充和描边颜色。
