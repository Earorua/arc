# Arc UI 优化交付记录

基线：发布备份及 clean-checkout 修正 `a0fe017`。分支：`codex/ui-warm-precision-20261028`。

## 实现内容

| 页面 / 区域 | 本次调整 |
| --- | --- |
| 全站框架 | 中文工作区导航、统一字号与留白、暖灰白背景和深朱红操作色；移除过期的全站开发提示 |
| 今日学习 | 短任务标题、完整目标正文、交付物和步骤优先；标明待补任务原定日期；完成标准与调整操作折叠 |
| 学习伙伴 | 大屏预留独立侧栏，小屏独立面板；关闭、隐藏、返回和切换页面时管理焦点；未开放状态使用用户可理解的说明 |
| 规划师 | 登录后直接围绕本次请求工作，保留前台生成期间不能离开的提示；建议仍需审阅和接受 |
| 岗位研究 / 设置 | 按实际阶段显示状态，中文表单与连续步骤；保留请求恢复、后台接收和新请求的区别 |
| 技能与资料 | 紧凑技能索引、单项详情、分类筛选和移动端返回；掌握标准、资源来源与核验日期保留 |
| 学习路线 | 当前阶段默认展开，其他阶段保留摘要；支持全部展开，保留前置依赖与暂缓技能说明 |
| 历史计划 | 使用统一工作区导航，明确只读，折叠计划版本；保留账户隔离与分页 |
| 作品证据 | 先看可查阅作品，版本记录折叠，技能统计放在后面；隐私、结构审核和确定性验证仍有区别 |
| 首页 | 复用完整样例入口，标明 45 分钟 / 18 周属于样例，已有账号继续进入学习工作区 |

## 保留的产品边界

- 勾选步骤仅存在当前页面；点击完成后才调用原有记录流程。
- 计划建议不会自动生效；历史计划不会切换当前计划。
- Research 的后台接收和 Coach 的前台生成语义保持原样。
- 账号、支付预算、模型服务、数据迁移、来源记录和作品验证策略没有改动。
- 未连接生产模型，未触发付费请求，未发布到正式域名。
