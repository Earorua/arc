# 工作区切页加载优化

目标：消除切页时的大字确认提示，减少串行等待，保持计划读取、账户隔离和失败重试的真实语义。

定位：`PlanningLoadBoundary` 将正常读取渲染为恢复面板的 h2，继承 `clamp(4rem, 8vw, 8rem)`。Today、Path 在 Arc 读取完成后才挂载 Planning hook，形成请求瀑布。其他页面已有并行读取。

- [x] 先增加短时无提示、慢速小提示、失败重试、两项读取并行的回归，确认旧实现失败。
- [x] 用共享 `WorkspaceLoading` 统一初始读取与计划读取：300ms 内不显示提示，超过后显示一行 14px 辅助文字；不使用标题或营销排版，不新增动效。
- [x] Today、Path 在会话页同时运行两个控制器，仍等结果可信后才显示内容。不引入跨账户缓存或改变保存流程。
- [x] 将错误标题收敛至 24px，保留即时告警与重试。导航在加载时继续可用。
- [x] 验证读取顺序、快速/慢速/错误状态、身份切换、SSR 水合与桌面手机样式。相关 200 项回归通过；最终聚焦 44 项通过，TypeScript 与 ESLint 通过。浏览器验证 1440px 和 390px 视口的 14px 提示及加载中导航。
- [ ] 构建并发布，核对正式版本与既有运行配置。
