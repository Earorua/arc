## 调整结论

已有路线时，首页原有三个通往 `/today` 的入口：顶部「学习工作区」、首屏「继续学习」、页尾「继续学习」。现仅保留首屏的一个主入口。

| 位置 | 调整 |
| --- | --- |
| 首页首屏 | 保留「继续学习」，仍进入今日学习 |
| 首页顶部 | 移除同功能「学习工作区」入口 |
| 首页页尾 | 移除第二个学习入口，保留结语 |
| 学习方法页、产品样例页 | 保留顶部「学习工作区」，便于返回学习 |

首页主入口仍根据当前状态显示「创建学习路线」「继续设置」「继续学习」「重新登录」或读取失败后的重试。草稿恢复、账号状态与跳转判断沿用既有逻辑。样例及学习方法链接保留，本次范围为首页的学习主入口。
