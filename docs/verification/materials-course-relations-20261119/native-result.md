## 为什么修正校验器而没有重跑规划

初版校验器在两个场景都错误要求 SQL 必备优先级行包含简历的 `practiceItemIds`。实际未变的上下文契约在该行展示胜出的主 JD 来源；只有符合条件的显式学习重点贡献来源时，才提供单独的实践／重点区分字段。SQL 必备优先级 0 会覆盖实践优先级 3。

修正版核对准确的主 JD 来源与优先级，并同时检查普通 `itemIds` 和可选 `practiceItemIds`，防止同事工作或 CSS 被计入来源。其他断言未改。原校验器、失败报告和日志保留；两个实际执行记录原样复用。

这里没有观察到“必备要求下面单独展示 SQL 实践优先级”的原生正例，因此不作该项声明。本人实践的正反边界另有已通过的实际上下文服务测试和课程关系测试，独立审阅确认不需要再建一个重复原生场景。
