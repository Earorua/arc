# Arc 切页加载体验修复 · 2026-11-08

已发布到 https://arcmaps.net/ 。切页读取不再显示「正在确认你上次的学习进度」大标题。

## 原因与调整

正常读取复用了异常恢复面板的 h2，字号继承 `clamp(4rem, 8vw, 8rem)`，最大 128px。页面切换重新挂载读取控制器；Today 和 Path 还在 Arc 数据完成后才开始 Planning 读取，形成串行等待。

- 共享 `WorkspaceLoading` 在挂载 300ms 后才显示一行 14px「正在加载学习内容…」，短时读取不显示文字，卸载取消计时器。
- 初始恢复与计划读取统一该提示；页头保留静态工作区说明，去掉重复加载文字。
- Today、Path 的两个控制器同时启动，仍等待可信结果后才呈现学习内容，原有账户隔离、写入与恢复规则不变。
- 真正读取失败仍立即显示错误与重试按钮，错误标题使用 24px 正文字体，重试失败后仍可再次操作。
- 导航保持可用。不新增跨账户缓存、动画或数据库变更，保留已发布墨青配色。

- 线上 `/path` 在未登录状态正常恢复为登录入口；已加载 CSS 包含新 14px 规则，旧大字提示未显示。线上未进行登录账户慢网测试；该部分由本地真实组件和控制器回归覆盖。
