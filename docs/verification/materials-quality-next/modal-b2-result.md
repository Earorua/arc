- **输出被截断。** 5 份均返回 `finish_reason=length`，恰好使用全部 4,096 个输出 token。4 份助手正文为空，1 份只有 118 个字符。17 个缺失字段中的 15 个、7 个缺失复核提示中的全部 7 个来自这 5 份。另有 2 个字段在完整输出中被遗漏。受影响的是 `resume-02`、`resume-09`、`jd-03`、`resume-10`、`resume-12`。
- **有一部分偏差产生在本机。** 对照保存的原始模型正文、产品解码和独立参考，再执行现有词语处理函数。14 个参考范围外的技能表述中，9 个已出现在模型原始输出中；另 5 个是模型返回了参考接受的原文词组，本机将其改成了规范名。例如模型返回“清洗空值记录”，本机写入了 `data cleaning`。另外四处涉及“增量加载”、`unit tests`、“组件测试”和 `spreadsheet`。这五例可以直接用现有回执复现。
- **课程与任务仍有三处不一致。** 三个被参考接受的原文词组“测试”、`inspect API error logs`、`asynchronous TypeScript behavior` 的实际课程映射和任务覆盖不符。这部分已有原句、模型候选和产品映射，可以独立做本地回放。
