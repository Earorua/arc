## 规划参考需要原生状态绑定

冻结的 14 个场景是独立行为契约。它们的抽象 `revision`、`audit`、任务和 Proof 不能未经说明直接当作原生产品记录。实际产品分别持有 document、review draft、selection、context、proposal 与 workspace 版本；一次事实确认增加 document revision，当前学习 workspace 不变，符合事实确认与能力／计划采用分离的设计。

本机实际服务探针已经验证一次合法人工事实确认，以及单项 guided、批量 independent 拒绝、单项 independent 的纯函数边界。后者不证明能力采用已经接通产品入口。独立审阅在真实内存 SQLite 中检查合法计划、完成记录与独立 Proof ledger，并保存完整前后记录，未提交成冻结 14 场景的成绩。逐字段、逐场景绑定见[规划审阅备忘录](materials-product-observations/evidence/product-planning-independent-binding-audit-20261107-v2.md)。

确认的主要结果如下：

- **存在需要修复的采用缺口。** 当新的学习重点、重点撤回或同岗位主 JD 替换没有改变任务顺序和日期时，服务返回 `no-change`，仅保存请求回执，仍保留旧的当前采用上下文。新选择存在于预览中，但没有完成当前采用状态的转换。
- **有重排的显式接受链路正常。** 独立声明的合法 observability 场景产生了真实 proposal，workspace revision 为 `2→3→4`。明确接受前保留 A 公司 JD，接受后切换到 C，保留简历、补充资料、完成事件、原任务集合、依赖和工时。这是单一原生场景，不代表全部 14 例通过。
- **自评采用缺少集成入口。** `adoptMaterialSelfAssessments` 目前仅在定义与测试中出现；现有计划的资料重排请求会保留原 audit，并报告新自评尚未应用。不能用纯函数返回值冒充已持久化的能力采用。
- **删除、冲突和过期必须按真实生命周期观察。** 删除撤销资料依赖并进入清理，保留规划与 Proof；未解决的高影响冲突阻断确认；在旧上下文之后产生完成事件会使其提议请求得到 `CONFLICT`。这几个动作不能统一伪造成规划修订加一。
- **部分固定输入不能直接映射。** 抽象两周预算不满足原生最少四周；`local:` Proof 地址不是合法原生公开 HTTPS artifact；两个 native JD slot 被拒绝。Proof 另有独立版本／审阅账本，不能以 audit evidence 或观察者临时摘要代替。后续必须独立审阅新的原生输入绑定，并保留原行为保护要求。

## 观测工具的证据边界

新增 JSON 采集器直接调用生产提取投影和 mapper。输入仅为已明确标识的合成构造资料；引用上下文是 fixture 声明，不是数据库认证记录。投影后的 item 不代表用户已确认；给组件传入显式学习意图不代表实际服务已采用。

采集输入由冻结原文标注单独生成，共 267 个场景：255 个唯一有限词位置、1 份零候选文档和 11 个显式意图变体。生成器只使用原文、来源、输入分类、提示与允许词，不读取课程 topic/coverage 或规划 expectedChanges。单词场景用于定位过滤和映射行为，不是完整提取质量输入。

第一次实际采集得到 267 个 `projected` 结果、252 条原生 term mapping、15 个没有 term 输出的场景（11 个原空词、3 个被过滤后的空词和1份空文档）。这仅表示投影函数返回，并不代表事实正确、用户确认或学习计划已采用。

3 个词在真实提取投影中被过滤，原始输入和过滤后结果均保留：

| 来源位置 | 被过滤原词 | 需要保留的语义边界 |
| --- | --- | --- |
| `jd-02-field-2` | 键盘可访问性 | 中文分词把尾部“性的”视为整体，词尾未命中 wordBoundary，形成边界假阴性。 |
| `resume-11-field-3` | configure a Kubernetes cluster | 前缀 `I cannot yet` 命中正向能力否定保护；该保护被复用于保留原词。主题仍应能表达，但不能转成正面能力证据。 |
| `resume-12-field-1` | 熟悉 SQL，可独立完成报表 | 规范化后的前缀“简介:”不在 heading 白名单，触发 namespace guard。不是对 independent 词的直接检查；仍须保留简介自称及后续核对边界。 |

独立[窄范围复核](materials-product-observations/evidence/product-course-independent-projection-filter-20261107.md)确认三者都通过原始候选/schema，全文和提醒保留，但结构化原词消失。这些位置不能因过滤消失而从独立质量分母中删掉；后续修复需区分中文字边界、标题语境和“保留主题／证明能力”两种语义，不能直接删除否定或权限边界检查。
