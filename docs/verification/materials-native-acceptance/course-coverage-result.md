# Bounded course-task coverage — offline acceptance

Date: 2026-11-19. Status: **accepted for this bounded product change**. This is not approval of model quality, the native planning matrix, Gate 1B or publication.

## Result and limits

The material preview now separates course-topic correspondence from actual taught-task coverage. Nine compact task anchors cite exact existing registry leaves. The service verifies those leaves against the current flagship catalog before reporting full, partial or unsupported scope. Full means the complete recognized narrow task, not an entire JD, an arbitrary tool specialization or the user's ability. Unsupported modifiers remain visible. Manual course choices and names alone cannot establish full coverage.

Explicit compound topics retain each relation's own source word; alternatives remain ambiguous. Existing actor/polarity practice checks, explicit self-assessment adoption and single-primary-JD authority remain separate. Coverage does not create new courses, award ability or silently adopt a learning focus. Research and changed/unverified course content do not inherit this flagship evidence.

Coverage fields are optional for saved historical previews, and the interface explains their absence. Equivalent mapping rows still group by meaning, including coverage, within the existing 256 KiB bound. The mapping version is `2026.11.6`; previous alias versions remain supported. No frozen evaluation asset or course content was edited.
